TECH PLAY GAMES — upload guide

PACKAGE CONTENTS
- index.html: homepage with 30 designed SVG game cards.
- games/: 30 separate game HTML entry files.
- game.css and engine.js: shared responsive game styling and gameplay engine.

UPLOAD TO GITHUB
1. Open your repository: https://github.com/techplaygames/Tech-play-game
2. Extract this ZIP on your phone.
3. Upload/replace index.html in the repository ROOT.
4. Upload game.css and engine.js in the repository ROOT.
5. Upload the entire games folder with all 30 HTML files.
6. Keep filenames and folder names exactly as shown.
7. Commit changes. GitHub Pages should be set to branch main and folder /(root).

IMPORTANT
The homepage links to games/<filename>.html. If you upload only index.html, game links will not work.
The games are lightweight 2D browser arcade games designed for mobile performance. They are not console/AAA 3D games. Ultimate Tic Tac Toe includes Friend mode and Easy/Normal/Hard bot difficulty. Other games include touch pads, keyboard controls, restart and score/lives.
